# 티카투카 (Ticatuka)

![티카투카 게임 화면](public/og.png)

실드와 알까기 규칙으로 상대와 겨루는 웹 기반 전략 주사위 미니게임입니다.

## 프로젝트 소개

이 프로젝트는 **Smilegate RPG의 MMORPG 《로스트아크》에 등장하는 미니게임 ‘티카투카’에서 영감을 받아 웹으로 구현해 본 비공식 팬 프로젝트**입니다.

《로스트아크》와 관련된 명칭, 원작 콘텐츠 및 상표의 권리는 각 권리자에게 있습니다. 이 프로젝트는 Smilegate RPG의 공식 프로젝트가 아니며, 학습 및 개인적인 포트폴리오 목적으로 제작되었습니다.

## 주요 기능

- 세 줄의 보드에 주사위를 배치하는 전략 게임
- 같은 숫자의 상대 주사위를 밀어내는 알까기 규칙과 애니메이션
- 제거되지 않는 실드 주사위
- 같은 숫자가 추가될 때마다 해당 숫자만큼 더하는 점수 보너스
- 초급, 숙련, 전문가 난이도의 CPU 상대
- 초급 난이도의 줄별 우세도와 추천 위치 안내
- 게임 초기화, 리롤 및 게임 규칙 안내
- 주사위 배치·알까기·리롤 효과음 및 음소거
- 같은 브라우저에서 새로고침 후 이어하기
- 난이도 변경 전 게임 초기화 확인
- 키보드 포커스 관리와 Escape 닫기를 지원하는 모달
- 반응형 화면 구성

## 점수 계산

각 줄의 기본 점수는 주사위 눈의 합입니다. 같은 숫자가 추가될 때마다 그 숫자만큼 보너스를 더합니다.

- `6 · 2 · 2` → 기본 10점 + 보너스 2점 = **12점**
- `4 · 4 · 2` → 기본 10점 + 보너스 4점 = **14점**
- `6 · 6 · 5` → 기본 17점 + 보너스 6점 = **23점**
- `6 · 6 · 6` → 기본 18점 + 보너스 12점 = **30점**

## 진행과 승패 규칙

양쪽 보드가 모두 차면 게임이 끝납니다. 이미 가득 찬 보드는 차례를 건너뜁니다.
3줄 중 2줄의 점수가 더 높으면 승리합니다. 해당자가 없으면 총점이 높은 쪽이 이기며, 총점도 같으면 무승부입니다.

초급의 **줄 우세도**는 현재 배치 후 빈칸을 무작위 주사위로 채운다는 가정의 참고 수치입니다.
무승부는 절반 반영하며 이후 알까기, 실드 보상, 상대 전략은 계산하지 않습니다. 실제 게임 승률이 아닙니다.

숙련·전문가 CPU는 리롤의 기대 이득이 충분할 때만 1회 기회를 사용하며, 굴린 후 기존 값과 새 값을 비교합니다.
보너스 실드도 줄의 점수와 우세 전환을 비교해 배치합니다.

진행 상황·리롤 선택·난이도·소리 설정은 현재 브라우저에 자동 저장됩니다.
알까기 애니메이션 도중 새로고침하면 직전 저장 상태로 복원됩니다.
브라우저 데이터를 삭제하거나 다른 기기·브라우저를 사용하면 이어지지 않습니다. 저장이 차단된 환경에서는 저장 없이 플레이할 수 있습니다.
리롤 창에서 Escape를 누르면 기존 숫자를 선택하며 리롤 기회는 이미 사용된 상태로 유지됩니다.

## 로컬 실행

### 요구 사항

- Node.js 22.13.0 이상
- npm

### 개발 서버

```bash
git clone https://github.com/starzzangna/ticatuka.git
cd ticatuka
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(일반적으로 `http://localhost:3000`)를 브라우저에서 열어주세요.

### 프로덕션 빌드

```bash
npm run build
npm start
```

## 사용 가능한 명령어

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 프로덕션 빌드 생성 |
| `npm start` | 빌드된 앱 로컬 실행 |
| `npm run lint` | 코드 린트 검사 |
| `npm test` | 점수·알까기·턴·CPU·저장 데이터 테스트 |
| `npm run typecheck` | TypeScript 검사 |
| `npm run format` | 코드 포맷 검사 및 정리 |

## 개발 및 검증

게임 공통 규칙은 `lib/game.ts`, 저장 데이터 검증은 `lib/game-save.ts`에 있습니다.
`npm test`, `npm run typecheck`, `npm run lint`, `npm run build`로 검증합니다.
GitHub Actions가 main 푸시와 Pull Request에서 동일한 검사를 수행합니다.

프로필은 128px WebP 파일을 사용하며 원본 PNG는 보존합니다.
린트는 CSS 주사위의 ARIA 역할과 미리 최적화한 정적 이미지 사용을 허용하도록
`prefer-tag-over-role`, `no-img-element` 규칙을 조정했습니다.
입력 보조 영역의 클릭은 입력창으로 포커스를 옮기는 보조 동작이며, 키보드 사용자는 입력창에 직접 접근합니다.
